## Question

ตอนค้นกฎที่เรียนมา ปุ่ม 3/3b จะใช้ **คีย์อะไร** เป็นตัวจับว่า "แถวนี้คล้ายของที่เคย MANUAL ไว้"?

---

## Context

จากเคสจริงใน 73 แถว MANUAL และงานตรวจสอบก่อนหน้า:

- บางแถวมีแค่รหัสไปรษณีย์ ไม่มีเขต/แขวง (เช่น วังทองหลาง Google คืน 10312/10240 ไม่ตรง dict 10310)
- บางแถวสะกดต่าง dict (Phlabphla ≠ Phlapphla 7 แถว EN; Phruttharam / Bang Sri Muang)
- บางแถว Google ติดจังหวัดผิด
- บางแถวข้อความบุบ/ขยะ (Y = "65000" ไม่ใช่ที่อยู่ — MD-9576; addr N/A 3 แถว; GeoErr 8 แถว)
- ฝั่งไทย (ปุ่ม 3) กับอังกฤษ (3b) ข้อความต่างภาษา — คีย์เดียวกันหรือแยก (ยังเป็น Not yet specified ใน MAP)

ตัวเลือกที่ต้องเลือกแนวหลัก (ผสมได้แต่ต้องมีหลัก):

1. ข้อความ Y ดิบทั้งก้อน  
2. Y หลัง normalize (ลบ Chang Wat, ช่องว่าง, lower)  
3. รหัสไปรษณีย์ + โทเคนแขวง/เขตที่สกัดได้  
4. พิกัดใกล้เคียง (ไม่แนะนำเป็นคีย์หลัก — เสี่ยงข้ามเขต)  

คีย์หลวมเกิน → ติดผิด  
คีย์แน่นเกิน → เรียนแล้วไม่เคย hit
