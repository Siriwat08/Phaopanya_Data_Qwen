## Question

ใครเปลี่ยน PENDING → APPROVED / REJECTED ได้ ผ่านช่องทางไหน และต้องมีหลักฐานอะไรก่อนอนุมัติ?

---

## Context

- ตารางแยกเพื่อให้มีคนคุมก่อนเข้า pipeline
- ทีมมี 1–2 คนดูแล Master Data (ตอนนี้คือผู้ใช้เองเป็นหลัก) — ยิ่งเรียบง่ายยิ่งน่าใช้จริง
- ต้องเรียบง่ายบน Sheets ไม่สร้างระบบอนุมัติหนัก

ตัวเลือกตัวอย่าง (เทียบกับของที่มีอยู่ในโปรเจกต์):

- กรองชีต SYS_GEO_LEARN แล้วเปลี่ยน STATUS ด้วยมือ (ง่ายสุด ไม่ต้องเขียนโค้ด)
- เมนู "อนุมัติแถวที่เลือก" แบบเดียวกับที่มีเมนู 🔑 Set SCG Cookie / อนุมัติเป็นชุด (เร็วขึ้นเมื่อกฎเยอะ)
- ต้องมี NOTE กำกับเหตุผลตอนอนุมัติ/ปฏิเสธ หรือไม่บังคับ

---

## Done when

มติบทบาทผู้อนุมัติ + ช่องทาง + ฟิลด์ที่ต้องเติมตอนอนุมัติ/ปฏิเสธ (APPROVED_AT / APPROVED_BY / NOTE ตาม schema ของ G01)
