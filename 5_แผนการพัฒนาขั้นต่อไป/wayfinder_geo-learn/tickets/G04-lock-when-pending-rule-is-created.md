# Lock when a MANUAL row creates a PENDING rule

**ID:** G04  
**Type:** `wayfinder:grilling` (HITL)  
**Status:** open  
**Blocks:** G05, G08, G10  
**Blocked by:** G01, G02, G03  
**Claimed by:** —

---

## Question

แถว MANUAL จะถูกสร้างเป็นกฎ PENDING ใน `SYS_GEO_LEARN` เมื่อไหร่ — ทันทีที่คนเซฟ, กดเมนูรวบ, หรือเฉพาะแถวที่ครบ U/V/W/X? และ 73 แถว MANUAL ที่มีอยู่แล้วจะ backfill เป็นกฎชุดแรกหรือไม่?

---

## Context

- คนอาจกรอกไม่ครบทั้ง 4 ช่อง (ใน 58 แถว CHECK_NOTE มีแถวที่ต้องอ่านหมายเหตุถนน/เลขคู่คี่ก่อนจึงกรอกได้)
- คนอาจแก้ MANUAL หลายครั้ง (ก่อนอนุมัติ / หลังอนุมัติ)
- ต้องกันกฎซ้ำจาก MD_ID เดิม / คีย์เดิม
- ปัจจุบันมี MANUAL 73 แถว (15 + 58) บนชีตทดสอบแล้ว — ต้องตัดสินว่า backfill ครั้งเดียวตอนเปิดระบบเรียนรู้ หรือเริ่มนับเฉพาะแถวที่กรอกใหม่หลังมีระบบ

---

## Done when

มติ trigger สร้าง PENDING + เงื่อนไขขั้นต่ำของแถว + พฤติกรรมเมื่อแก้ MANUAL ซ้ำ (อัปเดตกฎเดิม vs สร้างใหม่) + มติ backfill 73 แถวเดิม
