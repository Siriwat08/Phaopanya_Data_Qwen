# D01 — เก็บความรู้เป็นตารางแยก SYS_GEO_LEARN + PENDING/APPROVED

**ช่วงเวลาที่ตัดสิน:** ก่อนสร้าง map (2026-09-05) · บันทึกเป็นแฟ้มเมื่ออัปเดตแผน v2 (2026-09-06)  
**สถานะ:** ล็อกแล้ว — เป็นข้อตั้งต้นของ G01–G10 ทั้งแผน

---

## มติ

เก็บความรู้ที่ได้จากการกรอกมือไว้ในตารางแยก **`SYS_GEO_LEARN`** โดยแต่ละกฎมีสถานะ `PENDING` / `APPROVED` — ไม่เขียนกลับ `SYS_TH_GEO` โดยตรง และปุ่ม 3/3b จะใช้เฉพาะกฎที่ `APPROVED` เท่านั้น

## เหตุผล

- SYS_TH_GEO เป็นพจนานุกรมทางการที่ผ่านการตรวจทาน (มาจากแหล่งราชการ) — การเขียนกลับอัตโนมัติจะทำให้ตรวจย้อนไม่ได้ว่าแถวไหนมาจากคนและแถวไหนมาจากทางการ
- แยกตาราง + มีสถานะ = มีจุดพักให้คนอนุมัติก่อนกฎเข้า pipeline ตอบโจทย์ "มีคนคุมก่อนใช้" ของทีม
- ลดความเสี่ยงขยะเข้าฐานถาวร — กฎผิดถูก REJECT ได้โดยไม่แตะพจนานุกรมหลัก
- สอดคล้องนโยบายเดิมของโปรเจกต์: ไม่เดาตำบล/รหัส และไม่บังคับ auto-fill โดยไม่มีคนยืนยัน
